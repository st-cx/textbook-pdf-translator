# 题干、选项和真实阅读顺序

一个对象的像素没有变化，仍可能出现在错误的阅读位置。内部连续三原页检查中，162个保护对象的成品像素都通过，但直接目视发现：上一页右栏的题干，其选项被排到了下一张中文页的左栏前部，而题干落在后面的右栏。另一组普通续题被误分为侧栏，出现了不应有的框。

本次修复使用显式、逐元素绑定的布局计划。它只克隆排版输入的内容角色、组关系和栏位，不修改原文、资产、翻译任务、术语或语义复核记录。计划还检查原始记录哈希、连续成员、题号或续题前缀、选项顺序、原栏几何、字号与已有结构证明；真实侧栏、图、跨栏横幅和未解决的断词不在自动转换范围内。

实现位于 [exercise_flow_adapter.py](../textbook_pdf/exercise_flow_adapter.py)，由 [layout.py](../textbook_pdf/layout.py) 在生成排版源和接收实际位置时调用。没有计划时沿用默认流程；计划通过 `Book.profile.layout_only_exercise_flow_v1` 显式提供。适配层文件哈希进入启用计划的成品身份，不能把旧排版结果当作新实现结果。

实际 Typst 位置返回后，检查同一题组的输出页、栏和纵向次序。出现缺成员、错误切栏或读序倒置时，正式生成流程阻断，并保留先前正式 PDF。不能靠“源文件中的元素顺序正确”推断最终双栏读序正确。

长书分块排版前也核验完整题组。分块边界使用实际成员所在页推导，重叠的题组、图组及跨页数学内容共同决定边界；不能只信计划自报的页范围，也不能将缺父题的部分选区悄悄放行。没有启用计划时保持原分块行为。14项自创测试覆盖链条重叠、单页限制、部分选区及其它关联内容。[检查范围](../evidence/flow-partition-percentage-20261023.json)

实际冻结源的默认80个有内容原页边界原本就包含该处续页，属于阴性检查；这次修复证明了其它选区和79页限制下的拆链问题。它没有生成新的完整中文样页；缺译范围会在正式排版前停止，不能用旧局部成品冒充本次通过。

当前范围是两组已核对原书的窄样本。修后仍是三原页到四译页，162/162保护对象保持原尺寸并通过成品相对裁片的像素检查，四张实际成品均已直接目视。选择范围首项为上一题的续题时，使用明确的“父题在选择范围外”证据；这种选择专用计划不能直接当作全书计划。全书仍须补齐父题、逐组核对，并保留真正的侧栏。

技术样页检查没有加载主任务库中的全部语义和术语诊断，不能把局部技术报告的零提醒解释为此前提醒已全部解决。像素检查也不认证译文、裁片对原书完整性或全书观感。完整软件回归及范围见[验证记录](VALIDATION.md)；教材样页、译文和计划中的私有书稿内容不公开。
