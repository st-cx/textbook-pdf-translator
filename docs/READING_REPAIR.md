# 阅读稿缺译与回退修复（rc.7）

实际用户成品暴露了任务调度和重排缺陷。旧稿有24,074项有效译文，但只显示20,450项；189个原页整体保留原文，另有4,508个待译元素。待译元素包括题目、短标签、正文及数学碎片，不能把它们全部称为长段落。

## 已修复的通用缺陷

- **大题组永久跳过。** 旧实现把超过6个元素的同题组全部延后，续跑仍然延后。现在按完整元素发送最多6个ID，完整冻结题干、小问与选项作为只读上下文；已保存项只作上下文，不重复请求。任务身份、版本、公式及数字校验保持。独立论证复核仍走原联合流程。
- **图内窄框导致整页英文。** 未译标签保留原PDF字形、尺寸与颜色，其余中文照常重排。已译标签仅在原底图实际像素为空、没有其他标签且有边界证据时使用额外空间，保持8.5pt。阅读预览实测仍放不下时，仅将该标签回退为原生英文，保留译文并扣除实际中文显示数；严格排版仍要求修复。原生标签内的公式不冒充独立资产像素通过。
- **图形碎片和公式上下限竖排。** 对符合有限条件的原生对象使用保持来源相对坐标的空间单元。裸标点从其真实来源字形单独保留，不根据宽度猜位置；不改变源内容或整体压缩。
- **关联和分页。** 图注跟随显式锚点；星号题号保留原生标记；隐藏旧表不再吞掉仍有实际内容的单元格。分段和错误隔离共同保留跨页数学与题目单元。修复公式引导语孤页、强制换行后中文被拉开及同段提示被拆成小卡片。
- **大书合并缓慢。** 避免对所有PDF对象作通用去重，仅复用字节与完整语义字典均相同的嵌入字体程序引用。字体名称、编码、字宽、页面内容及图形流不改；合并可在分段边界安全停止。
- **重复统计等待。** 只对唯一资产路径做相同的实际路径解析，并复用一次计算的已显示/缺译集合，保留输出覆盖保护和资产SHA校验。
