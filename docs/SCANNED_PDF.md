# 扫描版与无索引 PDF

扫描扩展使用本地 OCR、版面和公式检测，随后沿用统一任务库、代理/API协议、公式保护和中文排版。扫描图中的公式、代码及图形保留完整原始合成画面，不依赖旧隐藏 OCR 层重建符号。无电子书签、无目录或无可靠印刷页码均不要求先补索引。

当前状态必须以实际样页质量报告为准：接通 OCR 或生成 PDF 不代表扫描识别、公式语义或全书视觉验收通过。扫描模型和运行依赖由发行版安装流程准备；缺失时按错误补齐，不会自动改用外部识别供应商。

## 先分析两页，不调用翻译 API

```powershell
.\.venv\Scripts\python.exe .\translate_pdf.py "扫描书.pdf" --stage analyze --pages 129,300 --ocr auto --ocr-dpi 300 --no-legacy-import --out "扫描小样"
```

- `--ocr auto`：默认值，数字页沿用原解析路径，扫描/隐藏 OCR 页进入本地扫描路径，支持混合书籍。
- `--ocr off`：禁用扫描 OCR，保留原解析与已有扫描限制诊断；不能靠此选项略过扫描内容。
- `--ocr force`：按图像重新识别选定页，用于验证没有可用文字层的来源；不表示自动认可识别结果。
- `--ocr-dpi`：150–600，默认300。识别框使用原图像素坐标，再按真实渲染尺寸映射回原 PDF；提高分辨率会增加时间与内存，不能补回原扫描没有的细节。
- `--scan-corrections`：经原图核对的本地修正 JSON，仅分析阶段使用。

这些参数只影响真正执行的分析。已有任务的 `--stage translate`、`review`、`layout`、`qa` 不重新 OCR，不因为默认扫描参数改变已接受译文。更换 OCR 设置或源修正建议使用新的 `--out`，保留旧证据及任务历史；不能在原任务目录换书或换页集合。

扫描原图必须正确合成前景、背景和遮罩。某些书的背景约120 DPI、带遮罩前景约360 DPI；只抽取一个低分辨率图像对象会丢字。识别与质量检查应针对实际完整页面。

## 人工修正需绑定原书与原图

从该页 `review.json` 取实际原书 SHA、图像 SHA、OCR 行 ID 及区域，建立如下 JSON；下面的占位值必须替换，不能直接提交：

```json
{
  "source_sha256": "原书实际SHA256",
  "pages": {
    "129": {
      "reviewed": true,
      "reason": "逐行核对原扫描图后修正术语",
      "image_sha256": "review.json记录的原始RGB图像SHA256",
      "line_map_sha256": "review.json中的实际OCR行映射SHA256",
      "line_text": {"实际OCR行ID": "核实后的完整原文行，可包含 ⟦R:实际region_id⟧"}
    }
  }
}
```

```powershell
.\.venv\Scripts\python.exe .\translate_pdf.py "扫描书.pdf" --stage analyze --pages 129,300 --ocr auto --scan-corrections "扫描修正.json" --no-legacy-import --out "扫描小样_修正"
```

图像 SHA 绑定的是完整 RGB 像素，不是 PNG 文件压缩字节。更改 DPI/裁切后图像哈希可能变化，旧修正会被拒绝。`line_map_sha256` 同时绑定当前OCR引擎、行ID/原文/坐标和保护区域；引擎、遮罩或行顺序变化也会拒绝旧修正。行内公式可在核实后的行文本中写 `⟦R:region_id⟧`，分析时转为不可变公式标记，避免OCR把公式两侧词语粘连；区域ID来自同一页review.json。需要指定印刷页码时可在该页修正中写 `printed_page`，必须有原图证据。省略 `regions` 保留检测区域；提供 `regions` 会替换该页完整保护区域列表，并非增量补丁，须包含所有需要保留的公式、代码和图形。所有 bbox 均为当次原图像素坐标。

## 质量报告怎样读

`quality_report.json` 的 `scan_source_checks` 与 HTML 的“扫描来源检查”独立列出：扫描页数、OCR单元、原图 RGB 哈希、可见墨迹、未归属墨迹和低/未知置信单元。原生 PDF 字形数与 OCR 单元数分开统计。

墨迹归属不证明 OCR 准确。CTC 词框/字符框为估计位置，高置信度不等于识别正确；原 PDF 字形为0、墨迹全覆盖或译文结构通过均不能证明没有漏字。低对比文字、彩色背景、照片、细小标点和公式边界仍需目视。极小孤立噪点有显式阈值和记录，未从原始未归属像素数中静默扣除。

没有可靠印刷页码时标“原 PDF 第N页”，不能假设全书固定偏移。罗马页码、标题页、插页及正文逐页对应关系均需检查。没有电子目录时沿经核验的标题和来源顺序建结构；完全没有目录的书也是单独的验收案例。

单页模型输入限制为4000万像素；过大时明确要求降低 `--ocr-dpi`，按页处理和保存检查点，不将全书图像同时载入。

扫描验收至少覆盖：正文、行内/独立分式和上下标、代码/图内标签、无页码页、无文字层与无导航信息输入；完成两页小样后，再做连续页和全书检查。OCR、翻译、语义复核、源像素检查及成品视觉检查分别记录，不合并成一个“已完成”。


## 扫描排版与选页测试

扫描版从已核验原图取纸色，在文字和原公式背后铺底，保留扫描字形及其灰阶，不重写数学符号；未知/过暗纸色会阻止直接正式排版并进入待修。扫描纸色处理拥有独立源码与版本绑定，数字版原排版器及模板不改。引导短句和紧随独立公式通过统一内容关联协议共同分页，不能只留下“于是有”。

不要将跨章节选出的页面重编号为连续原页来验收来源边界。无索引测试输入可以保留原物理页位置，未选页明确为空白测试占位页，分析时只选择实际填入的页；这种夹具不是整本扫描原书，也不计为空白页全书翻译。成品只显示实际来源页码，不附原书或跳转。
