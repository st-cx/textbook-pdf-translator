# 原书底色与中文重排

教材的浅色定义背景应跟随定义正文，不能只留下若干带底色的公式裁片。新增的显式适配器把一个页边标签和一段完整正文作为组合对象：正文固定字号，短组合整体换页，背景按实际中文高度生成，标签与首行对齐。

这是有限的来源设计适配，尚未自动识别全书所有框线和侧栏。源结构通过 `Book.profile.source_design_panels_v1` 声明成员、完整成员记录哈希、公式对象描述、原页图形记录、原始不透明 CMYK 和边距。成员缺失、过期、重复或次序不明时拒绝排版。过长而没有明确续页边界的组合也拒绝，不缩小正文。

Typst 0.15.1 会把部分 CMYK 分量量化为8位。适配器只在当前组合的实测位置及唯一、受限的矩形语法匹配后，恢复该背景的四个原色分量。它不重写导入公式。保存前后重新比较全部文字轨迹、Form 内容，以及实际字体程序、编码、字宽、ToUnicode 和资源引用；异常时保留原好文件。

最终 QA 再从实际 PDF 核对底色。更新文件哈希不能绕过检查；缺少成品、布局记录或组合轨迹都会报告错误。完整资源图按每页核查，保留单页20,000节点和256层依赖上限，避免把整本大书累计资源数误当作单页异常。

习题使用自然右侧参差的段落排列，避免短行及手动换行被强制拉伸字距。正文、习题、图注和公式字号规则保持各自统一。
