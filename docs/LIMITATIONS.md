# 当前边界与待办

本版本为 **2.0.0-rc.6**，提供[桌面自动翻译和阅读稿](AUTOMATIC.md)，支持手动调整翻译并发及显式供应商池。它可自动处理常规范围、保留疑难页并续跑；正式全书验收仍是单独阶段。[Rosen 全书进展](ROSEN_PROGRESS.md)

- 尚未完成任何大型教材全书翻译及全书视觉验收，不能把小样结果外推为100%准确。
- 尚无相同硬件、原书、模型、费用预算下的公开竞品对测，不能主张整体质量、速度或费用领先。
- OCR、版面与公式模型复用开源组件，未提出或训练新识别模型。扫描低分辨率、倾斜、装订弯曲、低对比和密集公式仍可能需修正；本版本未承诺自动去弯曲或手写识别。
- 缺文字层、缺书签或缺目录可建立任务，但章标题、阅读顺序和印刷页码仍须按实际证据核验；未实现全书自动生成可靠电子目录的保证。
- 数字页保留原矢量公式，扫描页保留原光栅公式。保留扫描裁片避免OCR改写公式，同时继承原图清晰度和语言；它不把扫描公式神奇变为高清矢量。
- 本版原生裁片适配器仅接受页面 `/Rotate=0`，文字本身的四种方向另有回归覆盖。原生页面旋转仍须先做带来源映射的坐标归一化，当前明确拒绝裁剪，避免把显示坐标和原生字形坐标混用；这与独立扫描图像链路的旋转处理不同。
- 图内标签、复杂跨栏/长表、脚注与浮动图关系可能仍需源结构修正，无法可靠分离时明确报告；不是任意书籍一键获得出版质量。
- 新增跨原页公式仅自动连接具有严格首尾、相邻页和括号证据的两段表达式；多段、过宽、缺少证据的情况仍需修复。可伸展数学字形的边界适配依赖固定 PyMuPDF 版本与可确认的嵌入字体。
- 图内标签使用固定字号，放不进现有区域时阻断，不缩字；区域之外的背景比对不能证明遮罩区域内的图线或标签语义正确。
- “像素通过”检查对象嵌入和几何，不能证明框外没有漏掉本应保护的符号，也不能证明OCR或翻译语义正确。
- 原生字符存在检查只核字符、字体和字号；可伸展字体的真实墨迹专项只覆盖所列目标字体。普通斜体数学字符的边缘笔画、图形分数线和运算符上下限关系仍需独立证据，不把某类字体的零风险外推为所有公式完整。
- 公式的只读文字上下文可能沿用PDF字形流顺序，尚不是已认证的二维数学表达式或LaTeX。根号、分数及上下标必须结合原对象判断；已知次序风险的任务需要修正或拦截，不能因为裁片像素完整就直接发送。
- 语义复核是难段/风险段与普通段分层抽样，不是每个段落均由人工审核。当前声明按各样本实际覆盖列出。
- 任务规则与版本约束降低串译和误用缓存风险，但术语选择仍需要协调者确认，风格一致性不是单靠哈希就能证明。
- 仅Windows x64 / Python3.13 / Typst0.15.1完成本地验证。完整锁定依赖安装较大；桌面入口使用本地Tk，未提供云端服务。
- 公开源代码不带教材、任务缓存、模型权重或运行所需中文字库；测试仅附四个自绘小字体。内部教材验证是汇总记录，不能在此仓库独立复现；自有合成demo与公开测试提供可复现的有限证据。

下一步可由用户先运行全书阅读稿，再按成品清单集中修复公式、图文、排版与页码；跨书验证及同条件竞品评测保留为后续工作。
