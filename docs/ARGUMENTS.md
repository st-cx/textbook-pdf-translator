# 完整论证的排版与联合复核

数学教材中的“前提一、前提二、横线、结论”有明确的阅读结构。只核对每一行文字，可能漏掉结论与前提的关联；只比较公式裁片，也检查不到原书横线被遗漏。

本模块为经来源核验的论证保存一个有序单元：父题、前提、结论、原生“因此”标记、分隔线和只读上下文。它是显式结构接口，尚未提供全书任意论证的自动识别保证。

## 排版

- 前提与结论按原顺序参与中文排版，保持角色字号，整个短论证共同分页。
- 原公式及结论标记保留不可变资产身份；标记已经包含在原对象中时，不重复绘制。
- 分隔线记录原位置、长度、线宽、颜色空间、颜色分量、透明度及绘制状态，按已核来源重建；不能用近似RGB颜色代替原CMYK绘制状态。
- 成品检查读取实际PDF，核对成员顺序、位置、原标记及横线。记录存在或编译成功都不能代替实际成品检查。

接口分别在 [argument_units.py](../textbook_pdf/argument_units.py)、[argument_layout.py](../textbook_pdf/argument_layout.py) 与 [argument_qa.py](../textbook_pdf/argument_qa.py)。

## 联合语义复核

模型收到完整论证、父题和只读上下文，联合判断否定、量词、条件方向及前提到结论的关系。原书故意无效的论证应忠实翻译，不能擅自修正成有效论证。结果按整单元保存，不由多个逐行通过拼成，也不生成虚构的逐行通过记录。

提交在一个数据库事务中重新读取当前持久化的成员、父题、上下文、资产、术语和文体规则，并校验请求与回复的版本身份。另一个进程修改了相关术语、资产或源记录后，旧会话中的通过不能覆盖新状态。复核失败和过期回复均保留记录。

相关实现为 [argument_review_runner.py](../textbook_pdf/argument_review_runner.py) 和 [argument_joint_store.py](../textbook_pdf/argument_joint_store.py)。`run_review` 支持显式 `argument_ids` / `max_arguments`；只复核普通段落时可传 `max_units=0, max_arguments=0`，避免扩大请求范围。

## 已验证范围

公开的自创夹具与 [生产接口回归](../tests/test_argument_production_overlay.py) 包含保存后PDF、原生标记、原CMYK线条、乱序/缺线负例、过期会话、父题和只读上下文资产变化、相关术语变化及事务边界。当前完整源码回归为892项，875成功、17项可选跳过、0失败/错误；测试未调用真实模型，见 [绑定回执](../evidence/source-regressions-20261024-argument-v4.json)。

上述证据证明接口和有限合成案例。Rosen 实际论证的翻译、强联合复核及连续中文页视觉验收另列于 [全书进度](ROSEN_PROGRESS.md)，不由软件测试自动继承。当前仍未完成全书验收，也没有同条件竞品领先结论。
