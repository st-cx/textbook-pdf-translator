# 显式数字规则与跨页联合复核（实验功能）

这些接口用于已经核对原书、能够准确指明来源的修复。默认分析流程不会自动为全书添加规则，也不会据此宣布全书通过。没有显式启用的元素沿用原任务与数字校验协议。

## 数字与单位

机械比较数字字符串会把 `2.9 million` 与 `290万` 误判为不一致，也可能漏掉真正的数量级错误。`numeric_policy.py` 对已明确启用的单个元素使用十进制定点值核对数量，并保留其它内容的原有检查。

数量规则目前支持三个有限场景：阿拉伯数字系数与千、万、百万、亿等数量单位；明确角色的英文书目日期；英文月份名称。歧义分组或未知规则拒绝处理，不猜测其含义。

每份规则绑定元素完整来源、实现文件哈希和规则内容，进入任务、只读上下文及提交版本检查。修改规则会使旧任务与旧译文绑定失效，必须重新验证；不会把旧候选直接认作有效译文。数字通过后仍要求独立语义复核。

这些规则需由修复程序在核对来源后建立；普通用户无需编辑 `book.json` 绕过数字报错。请先保留报错与原页证据。

## 百分比与百分点

另一个需明确启用的 `percentage_policy.py` 检查完整的阿拉伯数字百分比：数值、正负号、单位及出现次数分别对应。`2%`、`2` 和 `2个百分点` 不能相互替换；括号外的负号、数字后的变量或上下标也不能被忽略后仅比较内层数字。支持直接带符号的小数及完整配对的普通括号；分式、比值、函数、隐式乘积和未知边界继续拒绝，不尝试计算表达式。

这层检查与数量规则可以同时启用，各自绑定完整来源和实现哈希，进入任务、上下文及复核身份。未启用的旧元素沿用旧校验，不能据此声称已修复全库百分比盲区。原有普通数字、术语和公式占位检查仍然执行；新规则判定数值等值也不代表其它校验一定通过，更不能证明比率与对象的语义关系正确。

前几份私有候选先后被独立反例拒绝，未用于生产。当前候选的全部旧反例和新增边界已重新测试；合成测试及实际源登记仍是不同阶段。[本轮范围](../evidence/flow-partition-percentage-20261023.json)

## 跨原页段落

中文语序可能把英文下一原页开头的短语移到上一片段。逐片段审校可能把正确的整体译文判为漏译。`semantic_units.py` 允许两个已证明连续的正文片段作为一个完整单元复核，检查合起来无遗漏、无重复。

首版只接受相邻两个原页上的正文段落，间隔只能是明确列出的页眉。每个成员、只读邻文、页眉、源顺序、公式描述与实际文件、当前译文及规则均受版本约束。侧栏、传记、图表或其它正文插在中间时不能使用该协议；它们仍需另外恢复阅读顺序。

已登记显式单元后，可运行：

```powershell
python translate_pdf.py --out "试译" --stage review --review-provider example --review-unit-id UNIT_ID --max-review-units 1 --workers 2
```

`UNIT_ID` 必须已经存在于核验过的源结构中。指定单元时只审这些单元，不附带普通段落审校；参数不会推断或创建单元。未指定时，待审单元和普通段落共用有界并发、供应商限流和停止机制。

模型只返回完整单元的判定、具体问题和跨页覆盖检查，不返回补译或逐元素通过。提交时再次核对当前版本；另一个连接已修改源、译文、术语、资产或结果时，旧回复不能覆盖新状态。截断的完整单元不拆开审校，也不原样重复请求。

联合通过单独保存，不伪造两个逐元素通过记录。只有事先准确授权的当前失败诊断可被该结果解决；新增失败、其它版本的问题和历史记录保留。移除单元配置后，成员仍显示待复核，不能沿用不存在的逐元素通过。

## 实际验证边界

单元准备在同一 SQLite 读取事务内按批读取大 Book 的字段，最多32条路径一批，减少重复解析。每次引用仍核对实际资产文件，包括同一资产的重复引用；不靠上一次文件检查放行后续引用。真实冻结快照的两个单元，Book 字段读取分别从8/18次降到1/1次，总耗时28.298秒降至2.036秒；这是两单元准备环节的只读实验，零模型调用、零数据库写入，不是全书或 API 吞吐测试。[绑定汇总](../evidence/rosen-flow-query-cache-20261023.json)

优化后的实现哈希参与单元版本，旧联合通过不会自动转成新版通过。任务报告会如实显示待复核，待新源稳定后重新执行；不复制旧结论来维持通过数。

公开测试使用自创材料，覆盖数字量级、日期角色、月份、旧任务拒绝、事务回滚、实际资产路径、跨页整体判定和并发结果检查。真实书稿应用及当前结果见 [Rosen进度](ROSEN_PROGRESS.md)。软件测试通过不代表源结构正确或全书复核完成。
