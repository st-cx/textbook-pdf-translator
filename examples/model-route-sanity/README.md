# 自创模型路线小样

`corpus-and-gold.json` 包含14个审校案例、4个短翻译任务、固定术语/文体规则与本地答案。全部为本项目自创，未使用教材片段。

只把 `payload` 发给模型，不发送 `gold_not_sent_to_models`。核对 JSON 中所有编号、14项判断、公式标记与数字；四条短译文仍需人工阅读，关键词或结构检查不能代替语义检查。一次请求通过不能预测全书表现。

[本机实际结果](../../evidence/model-route-sanity-20261023.json)只有五条路线返回成功，共20条实际译文，另一条返回HTTP400。记录中的名称是请求路线；没有保存响应的实际模型名称。一次耗时不能用于价格、长期速度或模型质量排名。复现需自行配置网关与模型，可能产生费用；仓库不携带凭据，不自动请求API。
